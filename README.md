# dig console

Front-end layout for **dig.greglepage.com** — a DNS and email-deliverability diagnostic tool aimed at day-to-day MSP work (multi-record lookup, propagation checks across Cloudflare/Google/Quad9, SPF/DKIM/DMARC health, reverse DNS, and more on the roadmap).

This is currently a static preview: `index.html` renders the intended UI with real (but hardcoded) DNS data pulled for `greglepage.com`. No backend or live query capability is wired up yet.

Deployed via Cloudflare Pages, connected to this repo.
